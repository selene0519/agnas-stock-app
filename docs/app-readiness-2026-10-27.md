# MONE 완성도 보완 — 2026-10-27

## 이번 변경

- 홈의 CSV 직독 경로를 제거하고 종목 목록 API와 같은 데이터·성과·장세·운용 검증 경로를 사용한다. 조회 과정에서 매매일지를 추가 기록하지 않는다.
- 종목 상세 분석 API도 공개 추천의 가격·차단 상태를 연결한다. 기업·차트 분석은 유지하고, 현재 추천에 없는 분석 자료는 ANALYSIS_ONLY로 명시한다.
- 텔레그램도 같은 검증 결과를 사용한다. 검증 실패는 ‘후보 없음’과 구분하며, 관찰 후보를 오늘 진입 후보로 바꾸지 않는다.
- 생성된 추천에는 이미 성향/기간/보정이 적용되어 있다. 해당 입력 계약이 확인된 추천 가격·점수에 서버와 화면이 다시 배율을 적용하지 않는다. 기존 발표 가격은 매매일지와 대조할 수 있게 유지한다.
- 장전 계획의 유효 시작·종료 시각을 거래소 달력으로 계산한다. 휴장일·조기 폐장·서머타임을 반영한다. 만료, 잘못된 가격 구조, 불명확한 시각, 다른 투자 프로필의 대체 자료는 실행 가능한 진입 계획이 되지 않는다.
- 계획은 장전 1회 판단이다. 관찰 종목의 가격 도달을 실시간 진입 신호라고 간주하지 않는다. 개인 자본과 보유 위험이 없는 상태에서 수량이나 비중을 만들어내지 않는다.
- 같은 5분 안의 추천 파일 수정도 캐시가 감지하도록 정밀 파일 수정 시각을 사용한다. 검증된 공개 응답은 최대 1분 재사용하고 읽을 때 만료 여부를 다시 확인한다.
- 화면은 진입·관찰 각각 2종목을 먼저 보여주고 펼칠 수 있다. 시장 선택과 안전 배너를 연결했다. 유효기한은 KST로 표시하고, 만료 가격은 재산출 대기로 표시한다.
- SIDEWAYS 장세 표기를 정상 인식한다. 지표 표시에서 음수인 이평선 이격도와 0인 이벤트 위험을 누락하지 않는다. 한국 장 마감 판단의 서버 UTC/KST 혼동을 수정했다.
- 자기보정의 활성 후보가 없으면 NO_ACTIVE_CANDIDATE로 구분하며 정상 수집 중이라고 표시하지 않는다. 기존 승격·사전 기록·독립 검증 기준은 유지한다.

- 공통 추천 경로 로컬 측정: 국장 최초 약 1.5초, 미장 전체 최초 약 18.1초, 같은 캐시 구간 내 미장 반복 조회 약 0.016초. 배포 환경의 응답시간을 의미하지 않는다.

## 아직 완료로 간주할 수 없는 것

1. 최초 미장 검증 비용: 다음 단계는 예약 작업에서 검증 결과까지 미리 산출하고, 웹은 버전이 일치하는 결과를 읽는 구조다. 유효기간·데이터 버전 검증과 실패 복구를 함께 설계해야 한다.
2. 독립적인 성과 증명: 현재 버전·시장·프로필·장세별 비용 후 성과를 전진 기록으로 축적해야 한다. 후보 수 증가나 승률 표시 변경은 성과 개선의 증명이 아니다.
3. 자기보정 실험: 현재 보고서의 기존 승인 다수는 ALREADY_APPLIED이며 새 활성 후보가 없다. 신규 제안의 독립 검증과 사전 기록 조건을 충족해야 수집·승격할 수 있다. 이번에는 정상 표시를 고쳤으며 학습 완료로 포장하지 않는다.
4. 전체 종목 상세 분석과 보유 대응 화면의 통합 재설계: 추천 목록과 상세의 가격·진입 권한 연결은 고쳤지만 이벤트 근거, 포트폴리오 비중·상관관계까지 하나의 상세 계획으로 통합하는 작업은 별도 범위다.

수익성 검증 완료 또는 완전 자동 운용 완성을 선언하는 변경이 아니다. 잘못된 진입 허용과 서로 다른 가격 전달을 줄이는 기반 수정이다.
